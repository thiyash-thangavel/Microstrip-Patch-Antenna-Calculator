# Microstrip-Patch-Antenna-Calculator
Used an AI-augmented workflow (ChatGPT for logic and Claude for deployment),
Real-time Synthesis: Automates calculation of patch dimensions ($L, W, y_0$),
Interactive Diagrams: Integrated SVG views (Top, Side, Isometric) with auto-updating dimension annotations,
Simulation-Ready: Dedicated setup guides for CST and HFSS, including recommendations for mesh strategy and boundary conditions,
Technical Documentation: Features a comprehensive 14-equation reference manual and a 17-parameter guide,
PDF Reporting: One-click "Print-to-PDF" mode to generate laboratory-ready reports.
