Complete Formula Reference
1. Patch Width
W = c / (2f) × √(2 / (εr + 1))
c = 3×10⁸ m/s (speed of light)
Determined by resonant cavity model
2. Effective Dielectric Constant
εreff = (εr+1)/2 + (εr-1)/2 × [1 + 12h/W]^(-1/2)
Valid for W/h > 1
Accounts for fringing fields
3. Fringing Length Extension
ΔL = 0.412h × (εreff+0.3)×(W/h+0.264) / ((εreff-0.258)×(W/h+0.8))
Hammerstad formula
Models end fringing capacitance
4. Patch Length
L = c / (2f√εreff) - 2ΔL
Half-wave resonant length
Corrected for fringing
5. Ground Plane Dimensions
Wg = W + 6h Lg = L + 6h
6h clearance each side
Ensures negligible edge effects
6. 50Ω Microstrip Feed Width
For W/h < 2 (narrow strip): Wf = 8h × exp(A) / (exp(2A)-2) A = Z₀/60 × √((εr+1)/2) + (εr-1)/(εr+1)×(0.23+0.11/εr) For W/h ≥ 2 (wide strip): Wf = 2h/π × [B-1-ln(2B-1) + (εr-1)/(2εr) × (ln(B-1)+0.39-0.61/εr)] B = 377π / (2×Z₀×√εr)
Bahl and Trivedi, 1977
Target impedance: Z₀ = 50 Ω
7. Inset Feed Position y₀
Rin(y₀) = Rin(0) × cos²(π·y₀/L) Rin(0) ≈ 90 × εr² / (εr-1) × (L/W)² Solve for y₀: y₀ = L/π × arccos(√(Z₀/Rin(0)))
Z₀ = 50 Ω input impedance
Rin(0) = edge input resistance
8. Feed Gap (Slot Width)
g = h/2 (typical rule of thumb) For precise design: g = Wf × 0.5 (alternate)
Gap isolates feed from patch
Adjustable for matching
9. Feed Length
Lf = (Lg - L) / 2
Extends to edge of ground plane
Provides waveguide port access
10. Waveguide Port Dimensions
Port_Width = 5 × Wf Port_Height = 5 × h
HFSS/CST Wave Port standard
Must capture dominant mode fields
11. Air Box & Radiation Boundary
Air_Box_W = Wg + 2×(λ₀/4) Air_Box_H = Lg + 2×(λ₀/4) Air_Box_Z = h + t + λ₀/4 Rad_Boundary = λ₀/4 from antenna
λ₀ = free-space wavelength
λ₀/4 minimum separation
12. Mesh Cell Size
λ_g = λ₀ / √εreff Coarse: λ_g / 20 Recommended: λ_g / 30 Fine: λ_g / 50
λ_g = guided wavelength in substrate
Finer mesh → more accuracy, more RAM
13. Skin Depth
δ_s = 1 / √(π × f × μ₀ × σ)
μ₀ = 4π×10⁻⁷ H/m
σ = conductor conductivity (S/m)
14. Free-Space Wavelength
λ₀ = c / f
c = 3×10⁸ m/s
f in Hz, λ₀ in metres
Parameter Explanation Guide
Parameter Meaning Effect on Antenna Performance
f Operating frequency Directly sets resonant dimensions. Higher f → smaller patch. Scales all dimensions inversely with frequency.
εr Relative permittivity (dielectric constant) Higher εr → smaller patch (miniaturisation) but reduced bandwidth and efficiency. Low εr (Rogers 5880) preferred for high-performance designs.
h Substrate thickness Thicker substrate → wider bandwidth, lower surface wave losses, but harder to suppress higher modes. Typical range: 0.01λ₀ – 0.05λ₀.
t Conductor (metallisation) thickness Affects feed width accuracy and skin-depth losses. Standard PCB copper is 35 μm (1 oz). Thicker metal reduces resistance but complicates photolithography.
W Patch width Primary dimension controlling radiation resistance and bandwidth. Wider W → lower radiation resistance, higher bandwidth. W ≈ 0.5 λ₀/√((εr+1)/2).
L Patch length Sets resonant frequency. Approximately half-wavelength in effective dielectric medium. Small errors in L shift resonance significantly.
Wg Ground plane width Must extend at least 3h beyond patch edges on each side (standard: 6h total). Finite ground planes modify E-plane patterns and can cause back radiation.
Lg Ground plane length Same rule as Wg. The feed line must also be accommodated. Shorter ground planes tilt the beam and reduce front-to-back ratio.
Wf Feed line width (50 Ω) Calculated for Z₀ = 50 Ω to match standard connectors/instruments. Narrower Wf → higher impedance; wider → lower. Must match system impedance for low VSWR.
Lf Feed line length Length from patch edge to waveguide port or SMA connector. Electrical length adds phase shift. For simulations, extends to ground plane boundary.
g Inset feed gap (slot width) Small gap between feed line and patch interior. Prevents direct DC contact while allowing RF coupling. Typically 0.5 mm – 1 mm. Affects capacitive loading.
y₀ Inset feed position (depth) Distance the feed line penetrates into the patch. Controls input impedance matching. y₀ = 0 → edge feed (high impedance); y₀ = L/2 → centre (zero impedance). Optimise for 50 Ω.
Waveguide Port Width Width of simulation excitation port Set to 5×Wf to ensure all feed line fringing fields are captured. Too small → inaccurate S-parameters and port mismatch.
Waveguide Port Height Height of simulation excitation port Set to 5×h. Captures substrate and above-substrate fields. Critical for correct modal decomposition in HFSS.
Air Box Simulation bounding domain Encloses the antenna in free space. Must be at least λ/4 from radiating elements to avoid boundary reflections interfering with near-field accuracy.
Radiation Boundary Absorbing boundary condition surface Applied on air box faces. Simulates open space. Distance ≥ λ/4 ensures accuracy. PML boundaries can be used at λ/8 for more compact simulations.
Mesh Cell Size FEM mesh discretisation Coarser mesh → faster solve, less RAM, lower accuracy. λ/30 is recommended as a good speed/accuracy trade-off. λ/50 for final validation sweeps. Use λ/100 on feed gaps.
HFSS / CST Simulation Setup Guide
Wave Port Placement
  • Create port on the -y face of the feed line substrate cross-section
  • Port width: 5 × Wf — centred on feed line
  • Port height: 5 × h — centred on conductor layer
  • Assign Wave Port 1, mode 1 (dominant TEM mode)
  • Enable Renormalise impedance to 50 Ω
  • In CST: use Waveguide Port with same dimensions
  • Ensure port face does NOT intersect the patch boundary
Air Box & Radiation Boundary
  • Create a Box object centred on the antenna assembly
  • Lateral clearance: ≥ λ₀/4 on all ±x, ±y faces → Air Box width: —
  • Height clearance: ≥ λ₀/4 above patch → Air Box height: —
  • Assign Radiation Boundary (HFSS) or Open (Add Space) (CST) on all air box faces except the port face
  • Do NOT assign radiation boundary on the wave port face
  • For broadside patterns ensure air box is symmetric about z-axis
Mesh Refinement Strategy
  • Global maximum cell size: λ_g / 30 (recommended)
  • Add mesh operation on feed gap region: λ_g / 100 or 0.1 mm, whichever smaller
  • Add mesh on inset notch corners: radiused or ≥ 2 cells across gap width
  • Substrate layer: at least 3–4 cells through thickness
  • Conductor layer: if solved as 3D (not impedance BC), resolve skin depth — minimum 2 cells deep
  • For HFSS: use Initial Mesh Settings → Lambda Refinement then adaptive passes
  • For CST: use Mesh Type: Hexahedral with PBA; set cells per wavelength ≥ 30
Frequency Sweep Setup
  • Adaptive solve frequency: set to target f₀
  • Sweep type: Fast (Interpolating) for broadband; Discrete for pinpoint accuracy
  • Sweep range: 0.5 × f₀ to 1.5 × f₀ — covers full impedance bandwidth
  • Step size: f₀ / 200 for smooth S₁₁ curve
  • Request: S-parameters, Z-parameters, radiation efficiency, 3D radiation pattern at f₀
  • Convergence: ΔS < 0.02 between adaptive passes
  • Minimum 3 adaptive passes (5 recommended for final design)
Material Assignments (HFSS)
  • Substrate object: assign εr, tan δ, μr = 1
  • Patch & ground: use Finite Conductivity boundary (surface impedance) with σ value
  • For t ≥ 3× skin depth: model as 3D solid conductor
  • Air box region: assign vacuum (default)
  • In CST: Material Library → set same parameters under Properties
Post-Processing & Validation
  • Check S₁₁ < −10 dB at f₀ for −10 dB impedance bandwidth
  • Plot Smith Chart: confirm loop passes through or near 50 Ω + j0
  • Verify VSWR < 2:1 across operational bandwidth
  • Radiation Pattern: confirm broadside gain, check cross-pol level (< −20 dB ideal)
  • Radiation Efficiency: typically 85–98% for low-loss substrates
  • Compare simulated vs. calculated resonant frequency — expect < 2% error
  • If S₁₁ notch is off: tune y₀ (inset depth) and g (gap) iteratively
